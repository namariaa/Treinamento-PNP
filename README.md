# Microblog em react 

Esse é um projeto desenvolvido objetivando o aprendizado de react para a bolsa de estudos.
Ele consiste em uma espécie de rede social, microblog, no qual os usuários podem se cadastrar, fazer login, postagens e comentários, além de poderem vizualizar todas as publicações e comentários respectivos já feitos por diferentes usuários.
